# 🏐 Tournament Pro - スポーツ大会管理システム バレーボールをはじめとするスポーツ大会の運営を効率化する、Google Apps Script ベースの統合管理システムです。 ## 🌟 主な機能 - **リアルタイムスコア管理**: 試合結果を即座に反映 - **自動順位計算**: 勝点・得失点差を自動集計 - **トーナメント自動生成**: 予選結果から決勝トーナメントを作成 - **タイムテーブル管理**: コート別の試合スケジュール - **大会要項自動作成**: A4サイズPDF出力対応 - **QRコード対応**: スマホから簡単アクセス - **レスポンシブデザイン**: PC・タブレット・スマホ完全対応 - **4種類のカラーテーマ**: 好みに合わせてカスタマイズ可能 ## 🚀 セットアップ方法 詳細は `SETUP_GUIDE.md` を参照してください。 ## 📂 ファイル構成 詳細は `PROJECT_STRUCTURE.md` を参照してください。 ## 💡 使い方 1. 初回アクセス時にセットアップウィザードが起動 2. 大会情報・チーム・試合形式を入力 3. 管理画面でスコア入力や進行管理 4. 観客は専用画面でリアルタイム確認 ## 📄 ライセンス © 2024 Tournament Pro.
